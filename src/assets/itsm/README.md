# ITSM logos

Drop each ITSM's official logo here, named after the platform in lower case:

- `servicenow.svg` (or `.png`)
- `autotask.svg` (or `.png`)

The incident panel's **Create ticket** button picks them up automatically
(see `src/app/components/itsm.ts`). Until a file is here, the button shows the
generic ticket icon.

Square marks work best — the button draws them at 16 × 16 px.
